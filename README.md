# Бот-напоминалка по олимпиадам

Следит за олимпиадами по информатике и пишет в Telegram:

- **дедлайны регистрации** — за 14, 7, 3, 1 день и в день дедлайна;
- **начало этапов** — за 3, 1 день и в день тура;
- **изменения в Google-таблице** — сдвинули дату, открыли или закрыли запись, добавили этап;
- **новые даты на официальных сайтах** — для тех олимпиад, где сроки ещё не объявлены (Росатом, ИТМО, Ломоносов, МОШ и остальные).

Одно и то же напоминание дважды не приходит: отправленное запоминается в `state.json`.

## Установка (один раз, минут пять)

### 1. Зависимости

```bash
pip install requests openpyxl beautifulsoup4
```

### 2. Создать бота

В Telegram найди **@BotFather** → `/newbot` → придумай имя → он выдаст токен
вида `8123456789:AAH...`. Токен — это пароль от бота, никому его не показывай.

### 3. Заполнить config.json

Открой `config.json` и вставь токен в `bot_token`. Затем напиши своему боту
`/start` в Telegram и запусти:

```bash
python get_chat_id.py
```

Скрипт покажет твой `chat_id` — вставь его в `config.json`. Готово.

### 4. Проверить

```bash
python olymp_bot.py --dry-run
```

Ничего не отправит, только покажет в консоли, что собиралось отправить.
Отдельно проверить доступность сайтов:

```bash
python olymp_bot.py --check-sites
```

Должно открыться близко к 20 из 20. Если сбоит один-два сайта — ничего
страшного, бот просто напишет об этом после пяти неудач подряд. Если сбоят
все — скорее всего дело в сети или VPN.

Первый настоящий запуск пришлёт полный срез по всем олимпиадам:

```bash
python olymp_bot.py
```

## Автозапуск — уже настроен

В планировщике Windows создана задача **Olympiad bot**: каждый день в
**12:00** по местному времени компьютера (пояс UTC+7, то есть 8:00 по
Москве). Запускается через `pythonw.exe`, поэтому окно консоли не мелькает,
а вся трасса пишется в `bot.log`.

Полезные команды:

```bash
schtasks /query /tn "Olympiad bot"
```

```bash
schtasks /run /tn "Olympiad bot"
```

```bash
schtasks /delete /tn "Olympiad bot" /f
```

Сменить время — например на 9:00:

```bash
schtasks /change /tn "Olympiad bot" /st 09:00
```

Задача создана с флагом «запускать при пропуске расписания»: если в 12:00
компьютер был выключен, Windows запустит бота при следующем включении.
Дедлайн при этом не потеряется — напоминания привязаны к датам, а не к факту
запуска, так что придёт всё актуальное на день запуска. Но если компьютер
не включать неделю, напоминание «за 7 дней» придёт позже, чем за 7 дней.

## Настройки в config.json

| Поле | Что делает |
|---|---|
| `bot_token` | токен от @BotFather |
| `chat_id` | твой chat_id, его показывает `get_chat_id.py` |
| `sheet_id` | id Google-таблицы; можно подменить на свою копию |
| `remind_days_before` | за сколько дней напоминать о регистрации |
| `stage_remind_days` | за сколько дней напоминать о начале тура |
| `watch_sites` | обходить ли официальные сайты |
| `only_in_perechen` | не напоминать про олимпиады вне Перечня РСОШ |
| `my_olympiads` | если заполнить — напоминания только по этим олимпиадам, например `["Innopolis", "СПбГУ", "Технокубок"]` |

## Что бот знает и чего не знает

Источник дат — Google-таблица «Перечневые олимпиады». Если её автор обновит
дату, бот это заметит и напишет. Если автор забросит таблицу, даты устареют —
поэтому вторым контуром бот сам смотрит на сайты и сообщает о новых датах,
но решать, что эти даты значат, всё равно тебе.

Чего бот **не** делает: он не регистрирует на олимпиады и не заполняет формы.
Он только приносит сроки, чтобы ты не пропустил запись.

Отдельная неточность: для диапазонов с несколькими волнами
(«23–25.10 и 05–07.12») напоминание о начале этапа может сдвинуться на
день-два — такие строки разбираются приблизительно. Дату из таблицы бот
всегда присылает текстом целиком, так что это видно глазами.

## Файлы

- `olymp_bot.py` — сам бот
- `get_chat_id.py` — вспомогательный, узнать chat_id
- `config.json` — твои настройки (токен внутри, не делись файлом)
- `state.json` — память бота: снимок таблицы, даты с сайтов, отправленные напоминания
- `bot.log` — что происходило при запусках; сюда смотреть, если уведомления не пришли
- `.sheet.xlsx` — последняя скачанная копия таблицы

Чтобы бот «забыл» всё и начал заново, удали `state.json`.
